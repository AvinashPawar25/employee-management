\# Employee Management System



A full-stack Employee Management System built using React, Node.js, Express, PostgreSQL, and Prisma.



\## 🚀 Technologies



\### Frontend

\- React

\- Vite

\- JavaScript

\- CSS



\### Backend

\- Node.js

\- Express.js

\- Prisma ORM

\- PostgreSQL

\- Swagger

\- Helmet

\- Express Rate Limit



\## ✨ Features



\- Add employee

\- View employees

\- Update employee

\- Delete employee

\- Search employees

\- Filter employees by position

\- Pagination

\- Employee dashboard

\- Total employee count

\- Total positions

\- Average salary

\- REST API

\- Swagger API documentation

\- Input validation

\- Duplicate email validation

\- Error handling

\- API rate limiting

\- CORS security

\- Helmet security
